# Path of Exile 1 (PoE 1)

PoE 1 is a different game from PoE 2. Use `path-of-exile-2` for PoE 2 questions, and do not carry PoE 2 mechanics (e.g. the flat -60% resistance penalty, Spirit) into PoE 1 advice.

## When to Use
- Build, ascendancy, skill, gear or league-starter recommendations for Path of Exile 1.
- Reviewing a Path of Building (PoB) export or character for PoE 1.

## Sources
- Items, gems, passives, mods: https://poedb.tw/us/ and https://www.poewiki.net/.
- Build popularity and meta: poe.ninja builds. Cross-check against a recent patch-version guide, since balance shifts each league.
- poe.ninja character pages are client-rendered; ask for a PoB code or sheet numbers instead of scraping them.

## Recommendation procedure
1. Filter candidates by the preferences below before ranking by power.
2. State the single main skill, the activation (ideally one button), and the source of the kill effect (explosion, shatter, etc.).
3. Note budget tier and league-start viability.
4. Flag anything that needs frequent manual input (flasks, mines, totem juggling, aura swapping) so the user can judge APM.

## This user's build preferences
- Low-APM, primarily one-button active gameplay.
- High-impact screen explosions and shatter effects.
- Dislikes Righteous Fire's passive walk-and-kill style; do not recommend it.
